# BLOK - the brutalist, web standard, obvious web UI library

BLOK is the UI system based on Brut RB's ethos - web standards, brutalist web design, minimal
configuration and choices, and obviousness over minimalism.

BLOK should allow you to create a good looking user interface with minimal CSS and JS by using semantic
elements and a minimal set of custom attributes/classes.

## Install

```
npm install blok
```


## Usage

See [the docs](https://brutrb.com/blok).
